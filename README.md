# University-Transportation-System

This is a Java-based console application that simulates a university transportation (bus reservation) system. The project is intended for educational purposes and does not include a graphical user interface (GUI) or web front-end.

## Project Overview

The system models different types of users and operations within a university's transportation framework. It focuses on object-oriented principles, showcasing how different roles interact within a reservation system using inheritance and encapsulation.

## Key Components

Member (Base Class): Common functionality for all user types.
Student: Simulates booking and canceling reservations.
Conductor: Can view and manage bookings.
Driver: Accesses route and schedule details.
